# Sistemas Microbiológicos — Material de Clases

Repositorio con el material completo de los talleres prácticos.

## Estructura

| Carpeta | Contenido |
|---|---|
| `modulo1_16S_DADA2_QIIME2/` | Pipeline 16S: calidad, denoising, ASVs, taxonomía, diversidad |
| `modulo2_DESeq_PyDESeq2/` | Análisis de expresión diferencial: conteos, normalización, volcano, heatmap |
| `modulo3_dudas/` | Sesión de consultas y trabajo supervisado |
| `actividad_evaluada/` | Datasets por grupo para la actividad evaluada |
| `environment/` | Archivos de entorno conda/pip para reproducir el análisis |

## Requisitos

- [QIIME2](https://docs.qiime2.org/) (Módulo 1)
- Python ≥ 3.9 con `pydeseq2`, `matplotlib`, `seaborn` (Módulo 2)

Ver `environment/` para instrucciones de instalación detalladas.

## Uso

Cada módulo tiene su propio `README.md` con los objetivos, instrucciones paso a paso y el notebook correspondiente.
