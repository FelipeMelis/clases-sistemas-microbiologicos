# Actividad Evaluada

## Descripción

Cada grupo recibe dos datasets distintos:
- Un dataset **16S** para analizar con el pipeline de QIIME2/DADA2.
- Un dataset de **conteos** para analizar con PyDESeq2.

Deben reproducir la misma pipeline vista en clases y entregar un informe con los resultados.

## Entrega

- Notebooks con el código ejecutado y las figuras generadas.
- Breve interpretación de los resultados (incluida en el notebook o como documento aparte).

## Rúbrica

| Criterio | Puntaje |
|---|---|
| Pipeline 16S completa y sin errores | 25% |
| Interpretación de diversidad alfa/beta | 15% |
| Pipeline DESeq completa y sin errores | 25% |
| Volcano plot y heatmap correctos | 15% |
| Interpretación de resultados DESeq | 20% |
